# M9 stopped ROI and pixel-format implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Root owns builds, Git, evidence and integration review; implementers own assigned source files. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Apply capability-valid ROI/pixel-format changes while stopped without reopening the camera or resetting its frame-ID sequence.

**Architecture:** Prepare a candidate resource set on the control thread, attach it to the existing Apply request for worker-owned device mutation, and atomically publish the matching camera/context after success. Retain explicit review/Confirm/Start and presenter acknowledgement. Keep same-mode changes on the existing path.

**Tech Stack:** C++20, Qt 6 Widgets/Core/Test, GoogleTest, CMake/Ninja, Linux/GCC and Windows/MSVC.

**Spec:** [Stopped ROI/pixel-format design](../specs/2026-09-12-m09-format-roi-design.md), extending [M9 Task 4](2026-04-25-m09-presets-workstation-ui.md#task-4-camera-selection-and-safe-settings-dialog).

## Global Constraints

- Preserve device thread confinement, immutable frame ownership, source-ID continuity, bounded queues and the existing 250 ms retrieve budget.
- Stopped-only complete Apply; no automatic stop/restart. Fresh confirmation and new-context acknowledgement precede Start.
- Use full exact native pixel descriptors and complete ROI. Validate capabilities, increments, containment, checked sizing and existing per-session resource budget, with at most two control-owned resource sets during a transition.
- Preserve desired processing, typed requested/actual persistence and explicit Resume. A stale generation or unrelated lifecycle action cannot continue Resume.
- No real patient data, Basler adapter, dependency upgrade, performance claim or acceptance waiver. Retain `EVALUATION — NOT FOR CLINICAL USE` and existing paused/stale/orientation semantics.
- Build/test ownership is serialized by root. Agents write tests first and report readiness; root records RED before implementation is released.
