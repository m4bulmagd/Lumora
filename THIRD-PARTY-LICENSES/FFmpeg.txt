FFmpeg runtime dependency
=========================

Lumora's Qt Multimedia adapter dynamically uses the Qt FFmpeg media plugin.
No FFmpeg source was copied into Lumora's application implementation.

Pinned vcpkg source build configuration
--------------------------------------
Builtin baseline: 04a9d8e5212d01ee1dd9478eadd9caade4f8b0d4
Qt Multimedia override: 6.11.1, with the ffmpeg feature explicitly enabled
FFmpeg version at that baseline: 9.0.1
Upstream source tag: https://github.com/FFmpeg/FFmpeg/tree/n9.0.1

On Linux, Lumora explicitly enables FFmpeg's openssl feature for TLS/RTSPS.
The pinned port makes openssl depend on its version3 feature, which enables
FFmpeg's LGPL version 3 build variant when GPL components remain disabled.
On Windows, the pinned port selects Schannel when openssl is not requested.
Lumora requests neither the gpl nor nonfree feature. These source-graph facts
are separate from the verified official SDK runtime described above; the new
vcpkg source dependency graph has not yet been built as part of this record.
